# 単語学習を優先するおすすめ候補

本人の2026-10-07指示に対応した独立branch `codex/medace-vocabulary-first-20261007`。基準は公開182と、その公開後4件修正28e988d。公開後4件の通常配備と、本候補の公開判断を分ける。本候補は実装・検証までを進め、公開要否は親側で整理する。

`useStudentDashboardViewModel`は文法/和訳の弱点推薦を残語より先に主操作へ選び、日目標完了後も期限復習を差し置いて演習へ切り替えた。通常ホームの主操作を単語学習にする。明示plan、既存の学習教材、未選択初回の承認済みNaruの順で選び、明示配布課題・未解決の講師対応は既存の優先順を保つ。ゲストのNaru入口は既にあるため保持する。

文法と和訳は「ほかの練習」として選べる。追加操作は新語も返し得る既存DUE_FIRSTなので「続ける」と表示する。ホームの期限語数は教材横断集計であり選択教材の期限語数ではないため、主操作で復習件数を確約しない。「選択教材に期限語があれば優先」と表示し、実セッションの教材filterを維持する。空/承認待ち教材は一覧確認や許可された作成へ案内し、利用不可Naruの開放や文法への自動差替えをしない。

snapshotには教材の最終利用時刻がないため、学習済み教材の既存順を尊重し最後の教材を推測しない。共有server自動mission提案は明示plan無しの場合だけ利用可能Naruを既定にするが、割当済み課題の経路は変更しない。実セッションは既存認可とpreferred教材filterを維持する。SRS/卒業閾値、保存receipt、schema、履歴、原本、AI設定、料金を変更しない。

学習と単語小テストは、製品副題・重複ナビゲーション・回答に不要な反復説明を減らし、回答操作を通常のレイアウトへ戻した。学習の意味は全文を保持してページ表示し、例文・訳・補足は選択して開く。保存失敗、再送、教材名、問題位置、必要な意味・ヒント・訂正は残す。通常操作を一画面に収める対象は学習と単語小テストであり、教材管理・全履歴・全役割の全画面でスクロール不要になったとは扱わない。極端な拡大や長い補足は安全に読めるoverflowを許す。
