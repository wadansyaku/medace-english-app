# 提供中の機能に合わせたプラン説明

PR #57 の公開前レビュー `discussion_r4187132726` を確認した修復候補。基準は `7d379eb65fa4d6904d7447ec45c91c35e161631b`。この記録はローカル変更の証拠であり、本番反映・課金変更の記録ではない。

## 確認と修復

- パーソナルプランの `pricingNote` / `featureSummary` とプラン画面が、停止済みのAI教材化・画像/PDF抽出を利用可能と案内していた。手入力・CSVのMy単語帳、スターター教材・保存済み例文、標準学習プランへ説明を合わせた。画像/PDFの自動抽出が停止中であることも表示する。
- フリープランの小さなAI補助と、ビジネスプランのAI利用枠・高コスト機能自動調整の約束も除いた。保存済み教材、標準プラン、編集可能な講師通知テンプレートを案内する。
- 旧円建て利用額の大小から「教材作成と添削は通常どおり使える」「まだ余裕」と表示していた。取得済みなら「従来AIの参考記録」、未取得なら未取得として扱う。現在の機能の利用可否やGPT利用額の根拠にしない。記録値と割合の計算は変更していない。

価格、プランID、権限、`allowedAiActions`、旧予算・単価、広告条件、課金処理は変更しない。Writingの画像/PDF原本保存と、停止中の単語帳自動抽出を区別する。GPT下書きは別のcapability・承認・予算境界であり、有料プラン説明だけで有効化しない。

## 検証

実際のアカウント表示とプランパネルをSSRで描画し、個人有料の手入力/CSV・停止中抽出、無料の保存済み素材、事業向けの標準プラン/通知、全4プランの参考記録表示を確認した。旧利用額0/60/90%と未取得でも、利用可能なAI機能を約束しないことを検証した。

対象5ファイル63 unit、型チェック成功。既存の価格設定、AIなし標準プラン・通知、本人の単語帳保存の対象unitも成功。build・実Chrome・公開後の表示確認はrootの統合候補で実行する。新しいAPI呼出し、キー、外部生成、push、配備は行っていない。
