# 小テストジェネレーターの教材カタログ照合

実施日: 2026-10-02。本人がログインした既存Chromeセッションで、正規UIの「自分のリスト」48掲載の教材タイトル・版・件数を確認した。資格情報、権限追加、実生徒情報はこの監査へ保存していない。取得は本人の正規保有アクセス範囲のメタデータ列挙に限定し、市販教材本文の一括取得は行っていない。

この結果は**カタログの掲載状況・タイトル・版・表示件数の照合**であり、全単語/全語義/全用例が同じことは未確認である。件数一致も本文一致を証明しない。本番DBへの教材追加・修正は行っていない。

本番の公式教材は計45冊だが、48/45または48/39から網羅率を算出しない。4原本の収録状況をレベル1〜6の語彙重なりから推定しない。原本の監査とローカル取り込みは [4冊の監査](./october-content-audit-2026-10-02.md) に分けて記録した。

## 重複と版の未確定

- Formula600はgenerator側に2掲載。
- LEAP初版の1,935件は別名で2掲載。
- 速読英単語 入門編 改訂第3版の1,450件は2掲載。
- 英検 準2級 でる順パス単 5訂版の1,500件は3掲載し、1掲載は仮版。
- generatorには「ターゲット1000（5訂版）」1,000件と「ターゲット英熟語1000（版未記載）」1,000件が別にある。appの4訂版/5訂版との厳密な対応は未確定。版未記載を自動で4訂版に割り当てない。
- generatorの桐原書店「古文単語315」は4訂版の記載があるが、appの対応候補タイトルには版がない。315件の一致だけで4訂版対応と確定しない。

同じタイトル・件数でも別名の複製、仮版、別版を一つに統合しない。generatorのリストIDとappのbook IDを対応表として記録し、確認した版だけを正式な対応にする。

## 次の導入判断

1. タイトル未収録候補4冊と件数差5冊について、本人/講師が対象版と掲載範囲を確認する。
2. 正規機能で照合できる範囲、本人が権利を持つ提供データ、許可された出力を使い、番号・語義・例文・出典まで比較する。本文を取得できない対象は未確認として残す。
3. 4原本は独立した原本教材として追加する。発音未提供、副詞actuallyの意味欠損、索引の別名/誤記は原本監査に従って確認する。
4. 本番への追加・更新・削除・切り替えは保留。対象・影響・既存ID/履歴の保全・rollbackを確定して承認後に進める。

証拠は [generatorの48掲載metadata](../../output/content-audit/generator-own-list-metadata.json)、[本番公式45冊の集計](../../output/content-audit/remote-catalog-counts.json)。後者の `catalog_source = LICENSED_PARTNER` に限定して39冊を比較した。資格情報や非対象リストの私的内容は含めない。

原本4冊の対応namespace候補を、タイトルMedAse/MedAce/ナルシスト/Naru、source_contextの原本basename/中学生用名詞教材で限定して本番の正規読み取りを行った結果、[候補metadata](../../output/content-audit/remote-workbook-namespace-books.json)は0件だった。これは対応するnamespaceが確定できない根拠であり、別名や別範囲まで含めて「4冊の全語が未収録」と断言する根拠ではない。原本の本番反映と本文の完全一致は未確認。


## 本文照合の再開手順（接続復旧待ち）

正規URLは https://www.printgenerator.net/ 。Notion資料置き場のリンクと本人が認証したChromeの実画面で確認した。最後のブラウザー一覧ではChromeが接続対象から消え、既存セッションのリスト本文を読めなかった。この時点の制約はブラウザー接続であり、CSV機能や本人の閲覧権が存在しないとの判定ではない。ログイン情報を別ブラウザーへ転記する作業、私的API呼び出し、本文の大量取得は行っていない。

1. 本人の既存Chromeを再接続し、「自分のリスト」を開く。新しい資格情報・永続権限が必要なら本人の安全な入力へ引き継ぐ。資格情報やcookieをチャット・成果物・ログに保存しない。
2. 48掲載のmetadata証拠から、まず未対応候補4冊と件数差5冊を選ぶ。正規UIで出版社・版・リストID・収録範囲を記録し、複製/仮版を識別する。
3. 正規リストエディタにはCSVインポート/エクスポート追加の案内があったが、今回の対象リストでの利用可否は未確認。本人が保有する対象データを正規機能で出力できる場合だけ、承認された一時領域に保存して照合する。
4. appのbook ID・原番号・語義・品詞・用例・出典まで対応を作る。同じ単語だけの一致や件数一致で「全反映」と判定しない。取得できない対象は本文未確認として記録する。
5. 本人/講師の確認後に移行案を作る。本番へ書き込まず、今回の4原本namespaceと既存レベル1〜6の再編教材を分ける。

現在の結論：48掲載のmetadata照合は完了。全単語帳の本文完全一致、4原本のgeneratorとの対応、本番への全反映は未確認。
