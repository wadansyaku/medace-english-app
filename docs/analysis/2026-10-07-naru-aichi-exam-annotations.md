# Naruシストの愛知県高校入試出題済み表示

本人が「原本Excelの黄色は愛知県高校入試の出題済み単語」と確認したことを根拠に、原本座標単位の教材メタデータを追加する非公開候補。原本、語義・英例文・既存学習履歴、Naru一冊1530語と4品詞章、承認・全プラン閲覧条件を保持する。実生徒・答案・providerへの送信はない。

## 原本照合

18シートすべて条件付き書式なし。対象はsolid RGB `FFFFFF00`（SheetJSでは`FFFF00`）、tint0。名詞修正ログの淡い黄色`00FFF2CC`は「既存値の修正」用途であり、120セルすべて対象外。他の修正色、見出し、例文、注記を単語の印へ変換しない。

| 品詞 | 本文の黄色で公開可能 | 一意に照合できる索引 | 表示対象 |
| --- | ---: | ---: | ---: |
| 動詞 | 178 | 0 | 178 |
| 名詞 | 346 | 2 | 348 |
| 副詞 | 21 | 1 | 22 |
| 形容詞 | 89 | 0 | 89 |
| 合計 | 634 | 3 | 637 |

索引から追加した3語は、同じ原本・品詞で完全一致する本文が一件だけある `history`、`snow`、`along`。異なる語義の同形語へ一括で印を付けない。本文の黄色635候補のうち、副詞`actually`（R82C6）は訳が空欄のため既存どおり保留。索引の98セルは語義が複数または本文なしのため照合保留（重複索引を含むセル数）。索引だけから決められない未印の動詞語義は `decide to` R104C1、`visit` R27C1、`leave` R32C1。該当語の別語義が黄色でも、この3語義を自動で出題済みにしない。年・回数は原本にないため追加しない。

原本SHAと全637件の原本・証拠座標、語義、品詞、保留一覧は `data/naru-aichi-exam-annotations.json`。再現は `node scripts/audit-naru-exam-annotations.mjs --input-dir /Users/Yodai/Downloads --output-dir /tmp/medace-exam-audit`（ファイル生成のみ、D1書込みなし）。原本SHAが異なれば処理を停止し、再監査を要する。

## 保存と画面

0056は追加migration。既存の原本SHA・source link・本文座標・語義/POS・証拠の実際の塗り色をSQLでも検査し、注記台帳とwordの表示用flagを保存する。語義・品詞・出典・教材が編集されればflagを消し、再適用も変更された原本ID/語義を復活させない。既存七表の既存列は不変。新規Naru取込は原本のstage SQLとは別の `naru-workbooks.exam-annotations.sql` を生成する。空DBへ0056→原本stage→この注記SQLの順に適用する。既存原本入りDBでは0056だけで該当注記を追加する。公開承認SQL・access scopeは変更しない。

guest APIと認証済みAPIは同じ `toWordData` を使い、全4プランで同じ情報を返す。GETは`no-store`で、ゲスト画面は再訪時に教材を再取得する。古い端末カタログの推測で印を補完しない。

カード、単語検索、終了後復習、意味/スペル回答、単語クイズと結果一覧に共通の「愛知県高校入試 出題済み」を表示。文字表示と折り返し、隠れたカード面のaria-hidden/inertを維持する。意味/スペル以外の文法・文章問題へ印を広げない。
